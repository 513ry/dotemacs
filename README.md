## .emacs.d

Read through [config.org](config.org) to find out what this config does - it's
pretty self documented.

Clone this repository into your `~/.emacs.d`. `init.el` will compile
`config.org` and compile and install packages on your system next time you run
emacs.

## Custom

I use [VictorMono](https://rubjo.github.io/victor-mono/) font enchanted with [NerdFont](https://github.com/ryanoasis/nerd-fonts#font-patcher) patcher.
